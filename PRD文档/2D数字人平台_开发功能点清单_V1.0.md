## 1. 产品主流程

| 阶段 | 用户操作 | 平台产出 | 前置条件 |
| --- | --- | --- | --- |
| 1. 权益准备 | 管理员分配 2D 在线版或 2D 本地版形象训练次数，必要时分配设备授权 | 训练次数、设备授权码 | 已有平台账号 |
| 2. 形象训练 | 用户上传符合要求的训练视频并提交训练 | 在线版或本地版形象；本地版可区分播报形象、动作形象 | 有对应类型训练次数 |
| 3. 动作编排 | 为本地版播报形象关联一个或多个动作形象 | 可供数字人调用的动作编排 | 已完成本地版形象训练 |
| 4. 知识准备 | 新建知识库并上传文档训练 | 可关联数字人的知识库 | 文档格式及大小符合要求 |
| 5. 创建应用 | 创建数字人应用，平台自动创建一对一智能体 | 数字人应用码、专属智能体 | 已有可用形象 |
| 6. 应用配置 | 配置形象、背景、智能体问答、交互模式、热词和接入参数 | 可部署的数字人应用配置 | 数字人应用已创建 |
| 7. 设备部署 | 下载数字人软件，绑定应用码与设备授权码 | 可运行的数字人终端 | 本地版需满足显卡要求；设备授权未过期 |
| 8. 运营维护 | 查看对话日志、管理资源和资产、发布软件版本 | 持续可运营的平台与终端版本 | 具备对应管理权限 |

| TR-10 | 状态操作 | 在线版完成资料 | 在线版训练完成时填写 API 密钥、项目 ID，并上传形象预览图片 | API Key、项目 ID、预览图 | 三项均为必填；密钥按敏感信息处理 | P0 |

| TR-13 | 状态操作 | 不通过后重新上传 | 不通过任务可重新上传符合当前数字人类型规则的视频 | 新视频文件 | 上传成功后任务回到待训练状态，并保留历史不通过原因供审计 | P0 |
