# 资产管理功能说明

## 1. 功能概述

资产管理用于维护数字人平台使用的形象、动作、音色、预设背景、嘴唇模型和智能体人设模板。侧边栏入口为“资产管理”，页面路由为 `/assets`。本文以当前前端原型为准，重点说明音色管理的上传流程。

页面可切换“2D本地版”和“2D在线版”。本地版包含形象管理、动作管理、音色管理、预设背景管理、嘴唇模型管理、智能体人设模板；在线版包含形象管理和预设背景管理。

## 2. 资产列表与通用操作

- 根据版本和资产模块筛选列表，页面提供关键词搜索。列表展示资产名称、编号、版本类型、资产模块、文件信息和更新时间。
- 各模块可新增、编辑、删除资产。编辑时回填已保存的数据；删除前弹出确认。
- 形象和预设背景支持“设为默认”，当前默认项在列表中标识。形象、背景预览图可放大查看。
- 当前原型的资产数据保存在前端运行状态中，新建或编辑后可在当前会话中使用；尚未接入资产上传与持久化后端。

| 模块 | 当前原型的主要配置 |
| --- | --- |
| 形象管理 | 形象名称、项目 ID、性别、默认音色、预览素材；本地版可关联嘴唇模型，在线版填写 API 密钥。 |
| 动作管理 | 通用动作、自定义动作、通用走动动作和走动动作；按类型填写动作 ID、上传视频或配置关联及走动参数。 |
| 音色管理 | 音色名称、性别、音频素材，以及上传后生成并可修改的音频文案。详见第 3 节。 |
| 预设背景管理 | 透明、图片、视频、网页背景；配置预览图和对应的素材或网页地址。 |
| 嘴唇模型管理 | 上传 `.pth` 模型文件。 |
| 智能体人设模板 | 维护系统提示词，最多 5000 字。 |

## 3. 音色管理

音色管理位于“2D本地版”资产分类下。点击“上传音色资产”打开表单。

### 3.1 新增音色资产

1. 填写**音色名称**。
2. 选择**性别**，可选“女声”或“男声”。
3. 上传**音频素材**。文件选择器支持 MP3、WAV、OGG、M4A 格式；新建时必须选择文件。选中后立即展示文件名、文件大小和音频播放器，供用户试听。
4. 上传音频后，在下方自动填入一段**模拟识别文案**。文案处于可编辑文本框中，用户可对照音频修改；文案不能为空。
5. 点击“确认上传”后，原型自动生成资产编号和音色 ID，并保存音色名称、性别、音频文件名、当前文案及本次会话可用的音频预览地址。列表中显示新资产。

当前模拟文案为固定示例，与上传音频的实际内容无关。页面会明确标注“尚未调用 ASR 服务”，不能把它作为真实识别结果。后续接入 ASR 时，应以识别结果初填文本框，并保留人工修改能力。

### 3.2 替换、移除与编辑

- 重新选择音频时，试听播放器切换到新文件，文案重新填入模拟识别文本；用户可再次修改。
- 新上传的文件可以在提交前移除。新建时移除文件后不能提交；编辑已有资产时移除新选文件会恢复原文件和原文案。
- 编辑音色资产时回填名称、性别和已保存的文案。有实际音频预览地址的资产可试听原音频；不重新上传时保留原音频，选择新文件则替换。
- 保存修改后，重新打开编辑表单仍可看到已保存的性别和文案。删除资产时，当前会话中的音频预览地址随之释放。

## 4. 原型边界与后续对接

当前音频文案由前端固定模拟数据产生，**没有调用 ASR 服务**。音频和资产记录尚未上传到服务端持久化；浏览器对象地址只在当前会话可用。配置中的演示资产也不保证具有可播放的真实音频文件。

正式接入后端时，需保存原始音频、音色名称、性别、用户最终修改的文案和资产标识；上传后调用 ASR 获取真实识别文案，并处理识别失败、空结果和重试。前端应继续允许用户修正文案，且不能把模拟文案标记为真实识别结果。

## 5. 验收要点

1. 在“2D本地版 → 音色管理”中，新建音色只需输入音色名称、选择性别、上传音频；音色 ID 自动生成，不要求填写音色类型、语调、音速或描述。
2. 选择音频后可立即试听，并显示可编辑的模拟音频文案及“未调用 ASR”的提示。
3. 用户修改文案后保存资产，重新进入编辑页时，修改后的文案与性别正确回填。
4. 替换音频时文案重置为模拟识别文本；移除新选音频时，新增表单恢复为未上传状态，编辑表单恢复原文件及原文案。
5. 正式后端与 ASR 接入前，页面不得把模拟文案或会话内预览地址当作真实识别结果或持久化资源。
