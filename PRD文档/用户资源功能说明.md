# 用户资源功能说明

## 1. 功能概述

用户资源模块用于登记和管理用户接入的第三方智能体资源，供创建或编辑数字人应用时选择。侧边栏入口位于“知识库”下方，页面路由为 `/user-resources`。当前支持的资源类型为第三方智能体，配置内容包括服务地址、访问密钥和模型名称。

本文依据当前前端原型整理。页面内预置的资源和操作仅用于展示交互流程，尚未连接第三方服务或持久化后端。

## 2. 资源列表

- 页面展示资源总数。列表列出资源名称、服务地址、模型、脱敏后的 API Key、创建时间及“编辑”“删除”操作；有备注时，在名称下方显示备注。
- 预置资源显示“演示”标识。初始提供 3 条模拟资源：客服问答智能体、展厅讲解智能体、产品推荐智能体。
- 搜索支持按资源名称、服务地址、模型名称和备注匹配；搜索无结果与资源列表为空时分别展示对应的空状态。
- 列表中的 API Key 始终以掩码展示，不直接显示明文。

## 3. 添加与编辑第三方智能体资源

点击“添加资源”打开新增表单；点击列表中的“编辑”打开表单并回填现有配置。

| 字段 | 必填 | 规则与用途 |
| --- | --- | --- |
| 资源名称 | 是 | 用于列表展示及数字人应用选择，最多 50 个字符。 |
| 服务地址 | 是 | 第三方智能体的服务地址，必须是有效的 HTTP 或 HTTPS URL。 |
| API Key | 是 | 第三方服务访问密钥。输入框默认隐藏，可手动切换显示或隐藏；列表仅显示掩码。 |
| 模型名称 | 是 | 标识该服务使用的模型，并显示在资源列表及数字人应用的资源选项中。 |
| 备注 | 否 | 描述资源用途，最多 200 个字符。 |

- 提交时去除各字段首尾空格；服务地址格式不正确或必填项为空时提示错误，不保存。
- 新增成功后，资源出现在列表中，并可立即供数字人应用选择；编辑成功后更新同一条资源。成功操作会显示提示。
- 点击“取消”或关闭弹窗时放弃本次未保存的修改。
- 删除前弹出确认；确认后从资源列表及数字人应用的可选资源中移除。

## 4. 与数字人应用的关联

1. 创建或编辑数字人应用时，“接入智能体”提供“平台自动创建智能体”和“从用户资源选择智能体资源”两种方式，默认选择前者。
2. 选择“从用户资源选择智能体资源”后，必须从用户资源列表选择一条智能体资源。选项显示资源名称和模型名称；选中后展示服务地址、模型名称及演示资源标识，不展示 API Key。
3. 若没有可选资源，表单提示先前往“用户资源”添加；未选择有效资源时不能提交数字人应用。
4. 保存数字人应用时记录所选资源的 ID，并将资源名称用于关联智能体展示。该方式不自动创建平台智能体；选择“平台自动创建智能体”时按平台原有流程创建专属智能体。
5. 编辑数字人应用时回填已关联的资源。若资源已被删除，重新提交时需要选择仍然存在的资源；复制关联了已删除资源的数字人应用时，页面给出提示并阻止复制。

## 5. 原型边界与后续对接

当前 3 条预置资源的地址、密钥和模型均为模拟数据。新增、编辑和删除只修改浏览器当前页面会话中的前端数据；刷新页面后恢复初始演示数据。当前未测试服务连通性，也未向第三方智能体发起请求。数字人应用仅保存资源关联，不代表第三方智能体已经实际接入或可以调用。

正式接入后端时，需要持久化用户资源并按用户权限控制访问；密钥应由服务端安全保存，列表及常规读取接口不返回明文；资源编辑、删除与已关联数字人应用之间的处理规则需要在后端落实。第三方服务的连通性校验和实际调用属于后续集成范围，不应将当前演示状态视为真实接入结果。

## 6. 验收要点

1. 侧边栏“用户资源”位于“知识库”下方，点击后进入用户资源页面。
2. 页面初始显示 3 条带“演示”标识的模拟智能体资源；可查看、搜索、新增、编辑和删除资源。
3. 新增时必填资源名称、HTTP/HTTPS 服务地址、API Key 和模型名称；备注选填。非法地址或缺少必填项时不能保存。
4. 列表中的密钥始终脱敏；新增与编辑表单中的密钥默认隐藏，可手动切换可见状态。
5. 新增或修改的资源可在数字人应用的“从用户资源选择智能体资源”下拉列表中看到；选择后展示资源摘要，但不展示密钥。
6. 数字人应用选择用户资源方式时必须选中有效资源；删除已关联资源后，编辑或复制时按第 4 节的规则提示并处理。
7. 页面明确说明数据仅在当前会话有效、刷新后恢复演示数据，且尚未连接第三方服务。
