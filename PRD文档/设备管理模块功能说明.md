# 设备管理模块功能说明

## 1. 功能概述

设备管理模块用于查看已接入数字人设备、维护设备资料，并从设备详情进入路线地图，配置导览路线、点位引领和路线公共参数。侧边栏入口为「设备管理」，页面路由为 `#/devices`。

本文按当前前端原型整理功能与交互。设备列表、路线、点位及配置均使用模拟数据；真实设备通信、地图点位同步、远程控制、文件上传和服务端持久化尚未接入。

## 2. 页面与入口

| 页面 | 入口 | 主要用途 |
| --- | --- | --- |
| 设备管理 | 侧边栏「设备管理」 | 查看、筛选、刷新、编辑、删除设备及进入详情。 |
| 设备详情 | 设备列表「详情」 | 查看设备完整信息，进入路线地图，模拟重启或关机。 |
| 路线地图 | 设备详情「路线地图」 | 按地图查看已发布和待发布路线，创建、编辑、复制、删除路线，进入点位引领和公共配置。 |
| 导览路线编辑 | 「新增导览路线」或点击导览路线卡片 | 按「路线简介 → 地图讲解点 → 编辑路线」配置导览内容。编辑已有路线时也从「路线简介」开始。 |
| 点位引领 | 路线地图「点位引领」 | 管理单个地点的引领顺序、点位和播报文案。 |
| 路线公共配置 | 路线地图「路线公共配置」 | 配置让路提示语及导览语音指令。 |

## 3. 设备管理

### 3.1 列表与查询

- 顶部展示设备总数和在线设备数；列表展示当前筛选结果数量。
- 列表字段：设备名称、设备 SN、在线状态、软件信息、租户名称、IP、MAC、系统类型、创建时间、操作。
- 在线状态分为「在线」「离线」；支持按状态筛选。
- 搜索支持设备名称、SN、租户名称、IP、MAC、系统类型和软件信息的关键词匹配。
- 系统类型仅提供 `Android` 和 `Windows`；每台设备的软件信息为一条文本，例如「Windows数字人软件v1.0」。

### 3.2 列表操作与设备详情

| 操作 | 规则与结果 |
| --- | --- |
| 刷新 | 单台设备刷新；原型等待约 550 ms 后更新「最近刷新」时间并显示提示，不向设备查询实时数据，也不改变在线状态。 |
| 编辑 | 回填并修改设备名称、租户名称、IP、MAC、系统类型和软件信息。设备 SN、在线状态、创建时间不在编辑表单中；保存时 MAC 转为大写。 |
| 详情 | 展示列表字段及最近刷新时间、软件信息，并提供「路线地图」「重启」「关机」「编辑设备」。 |
| 删除 | 二次确认后从当前列表移除设备。 |
| 路线地图 | 按当前设备 SN 进入对应的路线地图页面。 |
| 重启、关机 | 先二次确认，再显示模拟执行提示；当前原型**不会向真实设备下发指令**。 |

## 4. 路线地图

- 路线按「已发布的路线」「待发布的路线」分区，以卡片展示路线名称和所属地图；顶部可按地图名称筛选。
- 点击导览路线卡片直接进入路线编辑页；编辑页回填已有信息，保存时更新原路线 ID，不新增副本。已有示例路线若没有讲解点，编辑页提示先选择讲解点。
- 卡片「复制」生成名称带「（副本）」的新路线，状态为待发布；「删除」需二次确认。
- 新建导览路线可选择「发布」或「保存草稿」。编辑路线点击「保存修改」保留原发布状态，点击「发布」将状态设为已发布。
- 原型中其他路线类型的卡片仍可打开简要详情，并在详情中切换发布/待发布状态。

## 5. 导览路线创建与编辑

### 5.1 路线简介

| 字段 | 规则 |
| --- | --- |
| 路线名称 | 必填，最多 60 字。 |
| 相似叫法 | 选填，最多 120 字。 |
| 简介 | 选填，最多 40 字，显示字数。 |
| 巡逻模式 | 开关；路线执行次数可选 1～5 次。 |

新建路线和编辑已有路线均从此步骤进入。点击「下一步」时校验路线名称。

### 5.2 地图讲解点

- 选择地图后可查看该地图的讲解点；支持创建地图、添加讲解点、单独编辑讲解点名称。讲解点名称不可为空、不可与当前地图其他讲解点重复。
- 「点位同步」在原型中生成名称为 `1`～`9` 的九个模拟点位，不调用设备或地图服务。
- 点击讲解点按顺序加入「生成路线」，也可点击已加入的点位将其移除。进入下一步前，至少需要一个路线讲解点。
- 路线结束位置可选「充电桩」或地图中的「接待点」；选择接待点时必须指定具体点位。
- 地图图片支持 PNG/JPG/JPEG，单文件不超过 500 MB；上传后在当前页面预览。

### 5.3 编辑路线内容

- 时间轴包含「开场白」、各讲解点及点位之间的「运动途中」内容。开场白、讲解点播报和途中内容均需填写**内容标题**与**播报内容**，保存后卡片展示标题和正文。
- 播报编辑支持在光标处插入 HTTP(S) 链接，上传图片或视频并预览、移除；卡片展示链接、图片和视频数量。链接以 Markdown 链接文本保存在播报正文中。
- 讲解点的「+」可选择「播报内容」「自由问答」「原地等待」。新增的配置作为卡片按顺序展示，「+」按钮始终位于卡片列表最后。
- 自由问答：可搜索、勾选或取消常见问题，至少选择一项；当前问题与回答为原型模拟数据。卡片显示已选问题及数量。
- 原地等待：填写等待时长，范围为 1～3600 秒的整数；卡片显示等待秒数。
- 自由问答与原地等待卡片均可再次编辑或删除。
- 「添加地点」通过下拉框选择当前地图中尚未加入路线的讲解点，不再要求输入点位名称。

## 6. 点位引领

点位引领为独立页面，提供地点搜索、点位刷新、添加、编辑和删除。列表按显示顺序排序，展示显示顺序、地点名、地图归属、出发时播报、让路提示、到达后播报、结束点及操作。删除需二次确认；「点位刷新」当前仅显示模拟刷新提示。

添加或编辑地点时填写以下字段：

| 字段 | 规则 |
| --- | --- |
| 显示顺序 | 必填，大于 0 的整数；新增时按所选地图已有记录给出下一顺序。 |
| 地图选择 | 必填，从已有地图中选择。 |
| 地点名 | 必填，从所选地图的点位下拉选择。 |
| 结束点 | 必填，从所选地图的点位下拉选择。 |
| 出发时播报 | 必填，最多 500 字。 |
| 让路提示 | 必填，最多 500 字。 |
| 到达后播报 | 必填，最多 500 字。 |

切换地图时清空已选地点名和结束点，避免跨地图选择无效点位。当前下拉选项由预置地图点位、已有点位引领记录和已保存路线中的点位组成；尚未对接设备实时点位接口。

## 7. 路线公共配置

「路线公共配置」以弹窗展示，按设备分别保存当前前端会话中的设置：

| 配置 | 说明 |
| --- | --- |
| 让路提示语 | 可选「开/关」，默认开启。开启时提示语必填，最多 50 字，显示字数；用于数字人遇到障碍时提醒用户。 |
| 暂停指令 | 默认「暂停」，最多 30 字。 |
| 下一站指令 | 默认「前往下一站」，最多 30 字。 |
| 结束指令 | 默认「结束」，最多 30 字。 |
| 继续指令 | 默认「继续」，最多 30 字。 |

点击「确认」保存；点击「取消」或关闭弹窗不提交本次修改。再次打开时回填当前设备在会话中保存的配置。语音指令的实际识别和设备控制尚未接入。

## 8. 原型边界与验收要点

当前设备列表为页面内模拟数据，重新进入页面或刷新浏览器后可能恢复；路线、点位引领和公共配置使用前端共享状态，可在本次单页应用会话中跨页面保留，但刷新浏览器后恢复初始数据。上传的图片和视频仅在当前浏览器会话中以本地对象地址预览，未上传到文件服务。

1. 设备列表字段、搜索、在线状态筛选及总数/在线数统计正确；编辑仅修改允许的字段，删除前确认。
2. 设备详情可进入当前设备的路线地图；重启、关机明确提示为模拟操作，不误称真实下发成功。
3. 点击导览路线卡片后从「路线简介」开始编辑，原路线数据回填；保存更新原路线，不产生同 ID 副本。
4. 地图讲解点可加入生成路线；「添加地点」仅提供当前地图未加入路线的点位；路线内容卡片顺序与「+」位置正确。
5. 开场白、讲解点播报、途中内容可保存标题、正文、链接及图片/视频；自由问答至少选择一项，原地等待秒数通过范围校验。
6. 点位引领表单的地图、地点名、结束点联动，显示顺序与三个播报/提示字段均可保存并在列表回显。
7. 路线公共配置的开关、提示语和四条语音指令可保存并回填；开启让路提示语时空文案不能提交。

正式开发还需补充设备与租户权限校验、设备状态和地图点位接口、路线及点位的服务端存储、媒体文件上传、语音指令执行、远程控制鉴权及操作审计。真实重启/关机和路线下发必须以服务端执行结果为准。
