# 音色训练功能说明

## 1. 功能目标与范围

在平台侧边栏新增“音色训练”模块，提供音色样本上传、音频文案确认、训练任务管理、原始音频试听和音色合成试听。入口位于“形象训练”下方，页面路由为 `/voice-training`。

训练素材有两种准备方式：

| 方式 | 定位 | 用户操作 |
| --- | --- | --- |
| 自由上传音频 | 主要方案 | 上传自行录制的音频，查看语音识别文案，核对或修改后确认并提交。 |
| 固定文案引导录制 | 辅助方案 | 选择平台提供的固定文案，在网页外按文案录音，然后上传音频，核对文案后提交。页面不提供网页录音。 |

两种方式最终都以“用户上传音频 + 用户确认文案”提交训练。音频和文案需要匹配。

## 2. 页面与交互

### 2.1 新建训练

1. 用户切换“自由上传音频”或“固定文案引导录制”。切换方式时清除当前上传文件和待确认文案。
2. 填写音色名称；上传音频时如名称为空，自动以文件名（去掉扩展名）填入，用户仍可修改。名称最长 50 个字符。
3. 上传音频后立即展示文件名、原始音频播放器和文案确认区。音频时长在后台校验，不延迟文案展示。
4. 只接受 WAV、FLAC、MP3，文件大小不超过 50 MB。建议时长 5–10 秒；只要音频有效且时长不超过 20 秒，就允许提交。超过 20 秒时提示实际时长并要求重新上传。
5. 音频无法读取或格式、大小不符合要求时，给出明确提示并阻止提交。音频时长校验中也不能提交。

### 2.2 自由上传音频的文案确认

目标流程：上传音频 → FunASR 识别 → 在音频下方显示识别文案 → 用户核对/直接修改 → 点击“确认文案无误” → 正式提交训练。

- 识别结果放在可编辑文本框中，并提示用户对照原始音频核对。
- 修改已确认的文案后，确认状态立即失效，必须重新确认。
- 点击“确认文案无误”时记录当前文案；提交时再次核对文案与确认时是否一致。
- 当前前端原型在上传后立即填入固定的**模拟识别文案**，并提供“恢复模拟文案”按钮。该文案不是对上传音频的真实识别结果；接入 FunASR 后应改为真实识别结果，并处理识别失败、重试和空结果。

### 2.3 固定文案引导录制

- 提供“自然介绍”“服务引导”“产品讲解”三段可选文案。
- 用户选择文案，在安静环境中自行录制，随后上传录好的音频；网页不调用麦克风录音。
- 上传后显示固定文案供用户对照音频核对和修改，确认方式与自由上传一致。
- 切换固定文案时，清除之前上传的音频和确认状态。

### 2.4 提交条件与反馈

“正式提交训练”仅在以下条件全部满足时可点击：已上传符合格式和大小要求的音频、音频时长已校验且不超过 20 秒、音色名称非空、文案非空、当前文案已由用户确认且确认后未再修改。按钮旁显示尚未满足的条件，例如“正在检查音频时长”或“请核对并确认音频文案”。

提交成功后生成训练任务，清空本次表单。当前原型将任务加入本次会话的前端列表，状态显示“待训练（演示）”；正式环境需要由训练服务创建、持久化并返回任务 ID 和状态。

## 3. 训练任务列表与试听

页面预置 3 条演示任务：晓冉·自然女声、云泽·沉稳男声、清和·温柔女声。列表展示音色名称、训练时间、素材文件名、训练方式和任务状态。

每条任务包含两种试听：

| 功能 | 交互 | 正式环境要求 |
| --- | --- | --- |
| 试听原始音频 | 点击播放器或“试听原始音频”查看训练所用的样本。 | 从任务保存的原始音频地址播放实际文件。新建的前端任务目前可播放本次上传的文件；3 条演示任务没有真实音频文件，暂用浏览器语音演示并在页面注明。 |
| 输入文案合成试听 | 输入最多 500 字，点击“合成并试听”，生成后播放音频。修改文案后清除旧合成结果。 | 使用已训练的音色调用 Qwen3-TTS 参考音频克隆合成接口，返回可播放的音频。原型在未配置服务时使用浏览器语音演示，不代表真实训练音色。 |

正式环境应仅允许已完成且可用的音色进行合成试听，并对失败、无音频返回和重复提交给出反馈。

## 4. 服务与接口分工

| 环节 | 指定服务/接口 | 输入与输出（业务要求） |
| --- | --- | --- |
| 音频文案识别 | **FunASR 服务** | 输入用户上传的音频；输出识别文案，供用户修改和确认。 |
| 音色训练 | **Qwen3-TTS 音色训练 - 上传音频接口** | 输入音色名称、原始音频、用户最终确认的文案等训练所需信息；输出任务/音色标识及处理状态。具体字段以实际接口文档为准。 |
| 音色合成试听 | **Qwen3-TTS 参考音频克隆合成接口** | 输入试听文案和所选音色所需的参考音频/标识；输出可播放音频。具体字段以实际接口文档为准。 |

推荐调用顺序：音频校验 → FunASR 识别（自由上传模式）→ 用户确认文案 → Qwen3-TTS 上传音频并创建训练任务 → 训练完成后使用 Qwen3-TTS 参考音频克隆合成接口试听。

### 4.1 服务地址与资源池管理

**语音识别与语音合成的服务地址必须从“资源池管理”模块获取**，不在音色训练页面写死。FunASR 地址从语音识别资源获取；Qwen3-TTS 的音色训练上传地址和参考音频克隆合成地址从对应的语音合成资源获取。调用所需的凭证、场景、模型等配置也随选中的资源读取，并由服务端安全使用。

资源池当前原型具有“语音识别资源池”和“语音合成资源池”分类，以及部分 APPID、APPKEY、Cluster、Access Token 等字段，**尚无上述服务地址字段与音色训练资源绑定逻辑**。开发时需补充服务地址配置、启用状态和资源选择/默认绑定规则，明确当前租户或用户使用哪组 FunASR 与 Qwen3-TTS 资源；缺少可用资源时应阻止真实识别、训练或合成调用并提示管理员配置。实际接口路径、鉴权方式、请求与响应结构以部署的服务接口文档为准。

## 5. 验收要点

1. 侧边栏可进入音色训练；两种方式均通过上传音频完成素材提交，固定文案方式没有网页录音按钮。
2. WAV、FLAC、MP3 可选；不支持的格式和超过 50 MB 的文件被拒绝。5–10 秒只是建议，14.3 秒等不超过 20 秒的有效音频可提交，超过 20 秒不能提交。
3. 自由上传后立即在音频下方显示可编辑文案；正式环境显示 FunASR 结果。文案确认后再修改，提交按钮应重新置灰并提示重新确认。
4. 音色名称为空时上传音频可自动填入文件名；只有所有条件满足，“正式提交训练”才可点击，并能看到任务状态。
5. 任务可查看音色名称、训练时间和原始音频；已训练音色可输入文案并通过 Qwen3-TTS 合成音频试听。
6. FunASR 和 Qwen3-TTS 的服务地址均从资源池管理取得；更换资源配置后无需修改音色训练页面代码。

> 说明：本文同时记录目标功能与当前原型行为。当前原型的识别文案、3 条历史任务和未接入服务时的合成试听均为演示数据，不等同于真实 FunASR 识别或 Qwen3-TTS 训练/合成结果。
