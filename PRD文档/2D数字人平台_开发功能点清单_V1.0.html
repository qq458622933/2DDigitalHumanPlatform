文档属性 内容

1. 产品主流程

阶段 用户操作 平台产出 前置条件
1. 权益准备 管理员分配 2D 在线版或 2D 本地版形象训练次数，必要时分配设备授权 训练次数、设备授权码 已有平台账号
2. 形象训练 用户上传符合要求的训练视频并提交训练 在线版或本地版形象；本地版可区分播报形象、动作形象 有对应类型训练次数
3. 动作编排 为本地版播报形象关联一个或多个动作形象 可供数字人调用的动作编排 已完成本地版形象训练
4. 知识准备 新建知识库并上传文档训练 可关联数字人的知识库 文档格式及大小符合要求
5. 创建应用 创建数字人应用，平台自动创建一对一智能体 数字人应用码、专属智能体 已有可用形象
6. 应用配置 配置形象、背景、智能体问答、交互模式、热词和接入参数 可部署的数字人应用配置 数字人应用已创建
7. 设备部署 下载数字人软件，绑定应用码与设备授权码 可运行的数字人终端 本地版需满足显卡要求；设备授权未过期
8. 运营维护 查看对话日志、管理资源和资产、发布软件版本 持续可运营的平台与终端版本 具备对应管理权限

2. 模块总览

编号 侧边栏模块 路由 核心目标 主要使用角色
M01 形象训练 /training 创建并管理 2D 在线版、2D 本地版形象训练任务 普通用户、审核人员、管理员
M02 动作编排 /orchestration 关联本地版播报形象与动作形象 普通用户、内容运营
M03 数字人 /digital-humans 创建数字人应用并配置形象、智能体、交互、热词和部署信息 普通用户、内容运营、实施人员
M04 知识库 /knowledge 上传、训练和管理数字人问答知识文档 普通用户、知识运营
M05 权益管理 /benefits 查看和分配训练次数、设备授权 普通用户、管理员
M06 资源池管理 /resources 管理 ASR、TTS、本地数字人授权资源 管理员、实施人员
M07 资产管理 /assets 管理在线版及本地版形象、动作、音色和背景资产 管理员、内容运营
M08 版本管理 /versions 管理不同数字人版本的守护、主控、前端程序 管理员、研发、实施人员
M09 平台使用教程 侧边栏底部入口 通过遮罩和高亮步骤引导用户完成核心业务流程 首次使用用户

TR-07 视频要求 本地版视频校验与提示 闭嘴不说话的正脸人物视频；分辨率不大于 2K；时长低于 30 秒；支持 MP4、AVI、MOV、WEBM；最大 50MB 时长、分辨率、格式、大小 选择本地版后展示对应要求，非法文件给出明确原因 P0
TR-08 状态操作 待训练审核 待训练状态可执行开始训练或不通过；选择不通过必须填写原因 不通过原因 未填写原因不可提交；提交后列表展示原因 P0
TR-09 状态操作 训练中完成 训练中状态可执行训练完成 训练完成时间 操作后状态变为训练完成并记录操作信息 P0
TR-10 状态操作 在线版完成资料 在线版训练完成时填写 API 密钥、项目 ID，并上传形象预览图片 API Key、项目 ID、预览图 三项均为必填；密钥按敏感信息处理 P0
TR-11 状态操作 本地版完成资料 本地版训练完成时填写形象 ID，并上传形象预览图片 形象 ID、预览图 两项均为必填，形象 ID 不可重复 P0
TR-12 预览图片 图片格式与预览 训练完成预览图片支持 JPG、PNG、WEBP、GIF；列表按 9:16 展示，点击可放大 图片文件、图片 URL GIF 可正常上传和播放；放大层可关闭 P1
TR-13 状态操作 不通过后重新上传 不通过任务可重新上传符合当前数字人类型规则的视频 新视频文件 上传成功后任务回到待训练状态，并保留历史不通过原因供审计 P0
