# 数字人应用功能说明

## 1. 功能概述

数字人应用用于创建、查看和配置数字人，并为每个应用生成独立的应用码。应用可接入平台自动创建的专属智能体，也可接入第三方 Open API 数据源。当前原型入口为侧边栏「数字人」，页面路由为 `#/digital-humans`。

本文以当前前端原型为准。表单创建、编辑、复制和页面提示已实现为原型交互；第三方 Open API 的连通性验证、真实请求转发、密钥安全存储及服务端持久化不在当前原型实现范围内。

## 2. 数字人应用列表

| 功能 | 说明 |
| --- | --- |
| 卡片展示 | 每张卡片展示 9:16 形象预览图、名称、数字人类型、分辨率、描述、创建时间和自动生成的应用码。模板应用在卡片右上角显示「模板」标签。 |
| 搜索与筛选 | 可按名称或编号搜索，并按数字人类型筛选。 |
| 分页 | 每页展示 4 条，提供上一页、下一页及当前页码。 |
| 应用码复制 | 点击应用码旁的复制按钮复制应用码。 |
| 卡片操作 | 支持设为/取消模板、删除、复制和设置；点击卡片主体进入数字人详情页。 |

## 3. 创建数字人应用

点击「创建数字人」打开表单。新建应用**默认使用 2D 本地版**，表单不再展示数字人类型选择项；编辑已有应用时保留该应用原有的数字人类型，不因编辑而自动变更。

| 字段 | 必填 | 规则与默认值 |
| --- | --- | --- |
| 名称 | 是 | 输入数字人应用名称。 |
| 描述 | 是 | 说明应用用途或使用场景。 |
| 数字人服务器地址 | 本地版必填 | 默认 `127.0.0.1`。仅本地版显示。 |
| 接入智能体 | 是 | 默认「平台自动创建智能体」；可切换为「第三方 Open API 数据源」。 |
| 详细分辨率设置 | 是 | 默认横屏 `1920 × 1080`。横屏可选 `1920 × 1080`、`3840 × 2160`；竖屏可选 `1080 × 1920`、`2160 × 3840`；自定义模式需输入宽和高（px，均须大于 0）。 |

创建成功后生成独立应用码，应用出现在数字人卡片列表。创建入口不要求用户手动选择平台智能体。

### 3.1 平台自动创建智能体

- 选择此模式时，系统在创建数字人应用的同时生成一个专属智能体，并与该应用一对一关联。
- 数字人详情页点击「智能体配置」后，跳转到关联智能体的详情页进行配置。
- 复制此类应用时，为副本创建新的专属智能体和新的应用码，避免与原应用共用智能体。

### 3.2 第三方 Open API 数据源

选择「第三方 Open API 数据源」后，表单额外展示以下字段，均为必填：

| 字段 | 输入要求 | 界面处理 |
| --- | --- | --- |
| `base_url` | HTTP 或 HTTPS 接口地址，例如 `https://api.example.com/v1`。 | 进行浏览器表单格式校验。 |
| `api_key` | 第三方接口密钥。 | 默认隐藏，支持点击「显示/隐藏」切换。 |
| `model` | 第三方模型名称。 | 普通文本输入。 |

- 此模式只为数字人应用记录第三方接入配置，不自动创建平台智能体。
- 数字人详情页点击「智能体配置」时**不跳转，也不切换页面内容**，直接提示：「请在关联的第三方智能体后台配置内容」。第三方智能体的问答、人设等内容由其自身后台管理。
- 复制此类应用时生成新的应用码，并保留第三方 Open API 配置，不额外创建平台智能体。

## 4. 编辑与模式切换

卡片「设置」按钮打开编辑表单，回填名称、描述、原数字人类型、服务器地址、智能体接入模式、Open API 参数及分辨率。用户可修改智能体接入模式：

| 切换方向 | 保存后的行为 |
| --- | --- |
| 平台自动创建 → 第三方 Open API | 保存三个 Open API 参数，应用解除平台智能体关联；不会自动删除已有智能体。 |
| 第三方 Open API → 平台自动创建 | 为应用创建并关联新的平台专属智能体，清除该应用的第三方接入配置。 |

编辑保存后，列表与详情页应读取同一份更新后的应用数据。API Key 在输入框中默认以密码形式展示，用户可主动切换可见状态。

## 5. 数字人详情页

点击数字人卡片进入详情。详情导航包含「形象设置」「交互配置」「智能体配置」「热词配置」「接入配置」。

| 模块 | 主要能力 |
| --- | --- |
| 形象设置 | 预览形象及画布；调整数字人位置、缩放比例与输出分辨率；本地版可配置音色和动作预览，在线版不展示本地版专属选项；支持透明、图片、视频、网页背景，并可维护多个背景及切换。 |
| 交互配置 | 配置交互模式、常见问题，以及唤醒词或打断词相关设置。 |
| 智能体配置 | 平台模式跳转到关联的智能体详情；第三方 Open API 模式仅显示提示，不跳转。 |
| 热词配置 | 维护识别热词；本地热词可填写错误词列表，云端热词无需填写。 |
| 接入配置 | 展示数字人软件设备部署要求，以及使用文档、更新日志和软件下载入口。本地版推荐 CPU i7-12700、32 GB 内存、RTX 4070/5070 显卡；在线版无独立显卡要求。 |

形象预览画布按应用创建时的实际分辨率展示。位置可使用百分比或 px，数字人可在画布中拖动并缩放。

## 6. 验收要点

1. 新建数字人时不出现数字人类型下拉框，默认创建为 2D 本地版，服务器地址预填 `127.0.0.1`。
2. 默认「平台自动创建智能体」；成功创建后生成应用码及一对一关联的专属智能体。
3. 切换为第三方 Open API 后，`base_url`、`api_key`、`model` 全部必填；未填完整不得提交。
4. 第三方模式创建成功后不生成平台智能体；点击详情页「智能体配置」时保持当前页面并显示指定提示。
5. 平台模式点击「智能体配置」仍跳转至关联智能体详情页。
6. 编辑表单能正确回填并保存接入模式与参数；复制应用后生成新应用码，并按接入模式分别处理智能体关联。

## 7. 后续对接注意事项

正式接入后端时，应由服务端加密保存 `api_key`，前端不得在列表、详情或日志中明文输出；编辑接口宜返回掩码或“已配置”状态。还需明确第三方 Open API 的请求协议、鉴权方式、超时重试、连通性测试与错误提示。当前原型仅保存界面配置，不代表已实现第三方智能体的实际调用。
